# ورّاق — قارئ الكتب التفاعلي

موقع يرفع فيه المستخدم ملف PDF فيتحوّل إلى كتاب حقيقي بصفحات تنقلب بالسحب أو اللمس، مع ظل وصوت ورق.

- يعمل بالكامل داخل المتصفح، ولا يُرفع الملف إلى أي خادم.
- يدعم الكتب العربية (الغلاف من اليمين) والإنجليزية، ويمكن التبديل بينهما من الأعلى.
- يعرض صفحتين على الشاشات الكبيرة وصفحة واحدة على الموبايل.
- يحمّل الصفحات القريبة فقط، فيتحمل الكتب الكبيرة.
- يتذكّر آخر صفحة وصل إليها القارئ لكل كتاب.
- اختصارات الكيبورد: الأسهم للتقليب، و Home / End للأول والأخير.

## الملفات

```
index.html   الصفحة الرئيسية
style.css    التصميم
app.js       المنطق
README.md    هذا الملف
```

## النشر على GitHub Pages

1. أنشئ مستودعًا جديدًا على GitHub، ويفضّل أن يكون Public.
2. ارفع الملفات الأربعة إلى الجذر: **Add file ← Upload files**.
3. افتح **Settings ← Pages**.
4. في **Build and deployment** اختر **Deploy from a branch**، ثم الفرع `main` والمجلد `/ (root)`، ثم **Save**.
5. بعد دقيقة تقريبًا يظهر رابط موقعك: `https://USERNAME.github.io/REPO/`.

## التشغيل على جهازك

افتح `index.html` مباشرة بالمتصفح، أو شغّل خادمًا محليًا:

```
python -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## تخصيص سريع

- الألوان: المتغيرات في أعلى `style.css` داخل `:root`.
- سرعة التقليب: `flippingTime` في `app.js`، بالميلي ثانية.
- جودة الصفحات: الحدّان في الدالة `estimateTargetWidth` داخل `app.js`.
